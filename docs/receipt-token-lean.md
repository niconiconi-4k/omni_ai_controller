# 凭证量化无信息损失去重（2026-10-02）

## 优化边界

只对GPT-6.1 Sol的新照片与全页视觉PDF链路启用紧凑模型输出协议。
旧模型、旧文字层兼容接口、银行流水、审计算法、主服务公共返回字段与界面不改。
模型、图像数量、页号、high清晰度、退款符号、税/账户/reference/日期角色/收入分项、
推理级别及输出预算全部保留。不给图像降清晰度、不跳广告页、不剪裁未知区域、不降低token上限。

## 模型无需重复生成的内容

| 内容 | 新处理 |
| --- | --- |
| 顶层主票财务事实与分类 | 服务端直接复制已选子票；原解析本来就以子票为准 |
| 顶层包摘要 | 不再要求模型生成；该字段原本不进入公共返回结果 |
| 票据起止页 | 从完整source_pages取最小/最大值，实际非连续页号仍保留 |
| relevance/relevance_reason | 服务端固定unassessed/deferred_to_audit，交后续审计判断 |
| 票据生成日/到期日ISO副本 | 从financial_facts复制；原始日期标签仍独立保留 |
| 本地Qwen模式的空分类 | 服务端补null/false/0占位，Qwen继续逐子票独立分类 |
| 重复的双方身份schema | 使用官方支持的$defs/$ref，所有字段与约束保留 |

适配器不计算金额/税、不推断身份或日期、不替模型作业务分类。
老格式响应仍可解析；严格JSON schema的财务字段全部required。

官方定义引用说明：
https://developers.openai.com/api/docs/guides/structured-outputs

## 验证及成本口径

- Controller123、Main229、Interface23项回归通过；旧数据库迁移版本4项维持。
- 新增9项回归：单页/非连续多页/12子票、GPT/Qwen模式，精简前后公共返回逐字段相同；
  严格schema保留全部财务字段、不修改原schema，广告仍不制造财务票据。
- 离线同构示例schema序列化字符7779→4273（约45.1%减少）；
  单票输出2527→1392（44.9%减少），12票输出18545→15721（15.2%减少）。
- 上述为**离线字符量**，不是实际API token/费用或真实模型准确率评测。
  没有为了测成本额外调用用户模型或重跑材料。
- 图像输入费用不变，因此不能保证总费用回到旧水平；真实节省看后续正常量化台账。
- 信息完整性和确定性适配可验证，但随机模型生成无法承诺每次字面结果完全相同。

不强行改缓存参数。官方提示缓存可以降重复输入费用，但不等于减少逻辑信息；
缓存存在最小长度、命中条件及新模型cache-write费率，不能未经验证承诺命中或95%总费用下降。

## 部署

只需更新Controller。发布前检查远端版本和三类processing任务；有活动任务则不重启。
不重启Main/Interface/Model/OCR/Database，不重置或自动重量化既有资料。
